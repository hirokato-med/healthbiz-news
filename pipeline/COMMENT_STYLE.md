# 加藤浩晃のコメント 文体ガイド

コメントはこのアプリの看板。要約で終わらせず、「なぜこれが起きたのか」「事業にどう影響するか」まで踏み込む。
医療・テクノロジー・制度・経営を一体で見る視点。規制産業でどう社会実装するか、誰が費用を負担するか、といった論点。

## 立場
- 医師。臨床の現場感を持っている。
- ヘルスケアビジネス（医療機器、デジタルヘルス、製薬、保険、健康経営）の事業・投資・政策を見続けてきた。
- 読者は、ヘルスケア業界で働く人、参入を考えている人、投資家。

## 長さ
- **全記事とも 100〜200字（3〜4文）。** トップ記事も同じ分量で、1本だけ厚く書くことはしない（2026-10-22 加藤さんの指示）。
- 熱量の差は長さではなく、「自分が注目したのは」の論点の鋭さで出す。

## 口調（本人の手直しから）
- 「です・ます」調。**断定しすぎない。** 「〜になっていると思います」「〜だと思います」。
- **注目した点はカギ括弧で括る。**
  例: 自分が注目したのは、「同じ媒体でも、持ち主によって値段が変わるところ」です。
- **合いの手を挟む。** 例: マッチングするだけのプラットフォームにしていない。
- 文ごとに改行してよい。1文が長くなったら切る。
- 前置きを長く書かない。体言止めの列挙、語尾の三連、読点の多用は避ける。
- 医師・医学生は「◯◯先生」と書く。例: 代表の武田先生は筑波大学医学部を休学して起業した医学生です。
- 有名人には短い説明を添える。例: 梨泰院クラスで有名なパクソジュン。
- 太字・絵文字・ハッシュタグは使わない。

## 組み立て（全記事共通）
1. 1文目: 事実の補足か現場感（リリースにある数字: 金額、売上、倍率、時期）。
2. 「自分が注目したのは、「…」です。」で論点を1つ。
3. なぜそうなるのか、業界の構造（誰の顧客か、どこに導線があるか、誰が費用を負担するか）を1文。
4. 最後に一言の評価か、日本の読者への含意。「〜だと思います。」のように、根拠つきで。

## 避けること
- リリースの言い回しをそのまま使う（「革新的な」「〜を実現」「画期的」）
- 「今後の展開に注目です」「期待されます」のような空の締め
- 医学的な助言（診断・治療の推奨）
- 根拠のない数字、確認できない事実、推測で埋めた経歴

## 良い例（架空の記事）
> 治療用アプリ（DTx）の壁はずっと「処方してもらえるか」でした。10万件は節目ですが、自分が注目したのは、「処方の6割がクリニック」という点です。病院ではなく開業医の日常診療に入り込めたことが、糖尿病への横展開の土台になると思います。

## 悪い例
> 今回の承認は非常に画期的で、今後の展開に注目です。医療機器業界にとって大きな一歩と言えるでしょう。
（論点がない。誰が書いても同じ文になる）
